## About Me

I am a senior software engineer with **8+ years of professional software development experience** delivering production cross-platform mobile applications and enterprise .NET solutions. My core focus is **C# and .NET**, with hands-on experience building applications in **.NET MAUI** and modernizing established **Xamarin.Forms** codebases through structured migrations to .NET MAUI.

My background also includes enterprise backend and API development with ASP.NET Core, cloud-connected systems on Azure, and data solutions using SQL Server and SQLite. I also work with **AI + .NET**, including Azure OpenAI, Semantic Kernel, retrieval-augmented generation (RAG), and LLM-powered application patterns.

> Most of my production work has been delivered through private company and client repositories. This public profile therefore represents a selected view of my work rather than the full scope of my professional experience.
